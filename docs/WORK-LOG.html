현관에 끼어 있던 줄다리기 게임을 깨끗이 제거. 이제 저장소엔 Speech-Therapy와 ebook만 남음.

삭제됐던 배포처를 다시 만들고, AI 키(GEMINI_API_KEY) 등록, 빌드 폴더를 Speech-Therapy로 지정.

5. 다음에 할 일 ⬅️ 돌아오면 여기부터!

🔴 1순위 — Vercel을 "Next.js"로 인식시키기 (이것만 하면 끝!)

Vercel 사이트 → speech-therapy 프로젝트 → Settings → Build and Deployment → Framework Settings

  1. 1Framework Preset을 Vite → Next.js 로 변경
  2. 2그 아래 Build Command / Output Directory / Install Command에 파란 토글(Override)이 켜져 있으면 모두 끄기 (특히 Output Directory의 dist 제거)
  3. 3저장 → Deployments 탭 → 맨 위 배포 → ⋯ → Redeploy (빌드 캐시 체크는 해제)
  4. 4성공하면 speech-therapy-nine.vercel.app 에서 "소리야 놀자 🐶"가 뜸 → 끝!
